## Design and Analysis of Algorithms (DAA) - Lab 06

This folder contains the C implementations and notes for DAA Lab 06, covering array and matrix complexities, convolution, reversal-based sorting, and dynamic programming problems.


## Questions Overview

**Part `01/`** – (Week 06, folder `01/`)

| Question | Description |
| --- | --- |
| Q01 | Worst-case complexity of 1D array operations and validation through C code |
| Q02 | Worst-case complexity of 2D matrix operations and validation through C code |
| Q03 | Convolution of vectors using an $O(n \log n)$ divide-and-conquer / FFT-style approach |
| Q04 | Sorting a permutation using reversal operations and analyzing the cost |

**Part `02/`** – (Week 06, folder `02/`)

| Question | Description |
| --- | --- |
| Q01 | Fibonacci number using Dynamic Programming |
| Q02 | 0/1 Knapsack using Dynamic Programming |
| Q03 | Longest Common Subsequence (LCS) using Dynamic Programming |
| Q04 | Matrix Chain Multiplication using Dynamic Programming |

## Prerequisites

To compile and run the programs in this repository, you will need:

* GCC or any standard C compiler
* A Linux/macOS/Windows terminal

---

This lab explores both algorithmic complexity theory and dynamic programming design strategies. Each question includes a small C implementation that validates the core reasoning behind the corresponding algorithm.
