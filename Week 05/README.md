# Design and Analysis of Algorithms - Lab 05

This folder contains the C implementations and outputs for DAA Lab 05.

## Questions Overview

| Question | Description |
| --- | --- |
| Q01 | Find the median of a list without sorting the full list. |
| Q02 | Find the k-th smallest element without sorting the full list. |
| Q03 | Implement Quick Sort for N elements, save the input/output to files, and display both on the terminal. |
| Q04 | Implement Heap Sort for N elements, save the input/output to files, and display both on the terminal. |
